# Smaragd Touch

Touch-Oberfläche für ein selbst gebautes Pokémon-Smaragd-Spiel im Browser (Emulator mGBA als WebAssembly):
Hochkant, Ziehen zum Laufen, Antippen statt A/B, Menüs und Kampf im Handy-Stil.

**Dieses Repository enthält kein Spiel.** Die App braucht eine ROM-Datei (`pokeemerald_modern.gba`), die du selbst aus dem
Quellcode baust. Sie wird beim ersten Start auf dem Gerät ausgewählt und nur dort im Browser gespeichert, sie wird nie hochgeladen.

Aufs iPhone: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“ → App dort starten → „ROM auswählen“.

Enthalten: mGBA (MPL-2.0, siehe `vendor/README-mgba.txt`) und die Schrift Press Start 2P (OFL, siehe `vendor/fonts/`).
